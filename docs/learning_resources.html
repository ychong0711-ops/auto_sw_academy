Auto SW Academy — 학습 자료 추천

이 가이드는 Auto SW Academy 프로젝트의 각 학습 영역(임베디드 C, AUTOSAR, CAN 통신, UDS 진단, 기능안전, 보안, ASPICE)에 대한 최신 강좌, 유튜브 재생목록, 도서, 공식 문서를 정리합니다. 모든 자료는 실무 적용 관점에서 선별했습니다.

학습 순서 팁: (1) 임베디드 C 기초 → (2) AUTOSAR 구조 이해 → (3) CAN/ISO-TP 프로토콜 → (4) UDS 진단 → (5) 기능안전 + 보안 → (6) ASPICE 프로세스. 이 순서가 Auto SW Academy의 EX1→EX4 구성과 정확히 일치합니다.

학습 경로 매핑

단계프로젝트학습 영역추천 학습 순서
1단계 EX1 (embedded_c) C 언어 심화, 비트연산, 레지스터, 링버퍼, 상태기계, C++ 템플릿/OOP/RAII ① C 복습 → ② 임베디드 C 과정
2단계 EX2 (mini AUTOSAR) AUTOSAR Classic 계층 구조, MCAL/BSW/RTE/SWC ③ AUTOSAR 개요 → ④ 계층별 학습
3단계 EX3 (comm_diag) CAN 프로토콜, ISO-TP, UDS 진단 서비스 ⑤ CAN 기초 → ⑥ ISO-TP → ⑦ UDS 심화
4단계 EX4 (safety_security) ISO 26262, E2E, SecOC, WdgM, ASPICE ⑧ ISO 26262 → ⑨ 보안 → ⑩ ASPICE

🎯 현업 적용 팁

  • AUTOSAR는 이론보다 설정(configuration)이 실제 업무의 80%입니다. DaVinci Configurator / EB tresos 스크린캐스트를 꼭 보세요.
  • DBC 파일을 읽고 쓰는 것이 CAN 개발자의 기본 소양입니다. Auto SW Academy의 generated/VehicleNetwork.dbc를 CANoe/PCAN-View로 열어보세요.
  • UDS 응답(NRC)의 의미를 외우지 말고 패턴을 이해하세요. 0x7F + SID + NRC. 모든 진단 도구는 이 패턴을 표시합니다.
